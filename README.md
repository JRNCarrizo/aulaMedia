# Aula Media

App de escritorio (Electron) para docentes: descargar videos, audio MP3 y subtítulos de YouTube, con recorte opcional.

## Uso rápido

```bash
npm install
npm start
```

Las descargas se guardan en:

`Documentos/AulaMedia/` → `Videos` · `Audio` · `Subtitulos`

## Generar instalador (Windows)

```bash
npm run dist
```

Los archivos quedan en la carpeta `dist/`.
